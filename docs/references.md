# References

Bibliography of the accompanying manuscript, *"Stress-Driven Degradation of
Li-Ion Battery Anodes"*. Numbering follows the manuscript.

## Method references used directly in this code

| Reference | Where it enters the code |
|---|---|
| [3] Christensen & Newman (2006) | The closed-form linear-elastic stress solution implemented in `anode_dis/christensen_newman.py` |
| [11] Cheng & Verbrugge (2009) | Analytic stress anchor for the galvanostatic spherical-particle case (verification context) |
| [10] Zhang, Shyy & Sastry (2007) | Graphite intercalation-stress magnitudes cited for qualitative comparison |
| [16] Sethuraman et al. (2010) | Silicon flow stress σ_Y = 1.5 GPa used in `anode_dis/materials.py` |
| [8] Liu et al. (2012) | Size-dependent fracture of Si nanoparticles — the experimental fragmentation scale the R_crit = 331 nm result is compared against |
| [13, 15, 17] Zhao et al. (2010, 2011); Bower & Guduru (2012) | Large-deformation / plasticity framing; the small-strain limitation is discussed against these |
